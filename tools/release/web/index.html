03 // 3-PART FLASH ARCHITECTURE

UPDATE WITHOUT LOSING YOUR PAIRING

When KEEP DATA stays selected, the web installer writes only bootloader, partitions, and app, leaving Bluetooth link keys and settings untouched.

STEP 1

PLUG USB DATA CABLE

Connect the CYD directly to a PC USB port in desktop Chrome or Edge. No toolchain and no microSD card needed.

STEP 2

CLICK FLASH & PICK PORT

Select the COM / ttyUSB port and leave KEEP DATA selected on updates (or choose ERASE ALL for a clean wipe).

STEP 3

PAIR GAMEPAD ON CONSOLE

Open the first Home tile (GAMEPADS), put a classic Bluetooth pad in pairing mode, and tap + PAIR A NEW PAD.

ESP32 4 MB FLASH LAYOUT (partitions.csv · DIO 80 MHZ) WRITES 0x1000 / 0x8000 / 0x10000 · SKIPS NVS & SETTINGS
0x001000 BOOTLOADER (25 KB) FLASH
0x008000 PARTITIONS (3 KB) FLASH
0x009000..0x010000 NVS / BT PAD PAIRING KEPT
0x010000..0x3F0000 APP + 14 TITLES (~2.0 MB / 3.88 MB) FLASH
0x3FE000..0x400000 BRIGHTNESS & BOOT ANIM KEPT

READY TO WRITE POCKETME TO YOUR CYD?

Press RST on the board if it does not restart automatically when flashing completes.

TROUBLESHOOTING
NO PORT IN BROWSER PICKER
  • Try a USB data cable (charge-only cables show no serial port).
  • Windows: check Device Manager → Ports (WCH CH341SER driver). If attached to WSL, run usbipd detach first.
  • Linux: add your user to dialout / uucp and ensure brltty does not grab CH340.
  • Close Arduino IDE, espflash, boardctl, or serial monitors.
STUCK AT "FAILED TO CONNECT"
Hold BOOT, press and release RST, release BOOT, then click Flash again. If needed, hold BOOT until writing begins.
DARK, WHITE, OR WRONG-COLOR SCREEN
Verify silicon revision is ESP32 v3.0+ and that your CYD uses an ST7789 display chip (ILI9341 variants are unsupported).
MANUAL CLI / ESPTOOL-JS FALLBACK
Terminal commands for espflash / esptool and manual esptool-js instructions live in docs/install.md.
